# Spatial Memory Analysis

Replication of Experiment 2 from Healey, Gibson, Uitvlugt & Gondoli (2021).

## Description
This project analyzes spatial memory recall using R. The dataset includes 168 adolescents (10-13 years old) who completed a spatial recall task under instructed recall conditions.

## Analyses
- Serial Position Curve
- Probability of First Recall
- Temporal Lag-CRP
- Spatial Lag-CRP

## Tools
- R / RStudio
- tidyverse, ggplot2, scales

## Reference
Healey, M.K., Gibson, B.S., Uitvlugt, M.G., & Gondoli, D.M. (2021). Recall Initiation Instructions Influence How Space and Time Interact in Memory.
